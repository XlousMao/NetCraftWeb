## Docker 排障（用户 Docker Desktop 环境）

- 现象：`docker compose up -d --build` 拉取 `python:3.12-slim`/`node:22-alpine` 失败，报 `dial tcp [2a03:2880:...]:443 connectex`（IPv6 无效地址 = Docker Hub DNS 被污染）。
- 根因：国内网络访问 Docker Hub 受限，未配置镜像加速。
- 关键教训：**Docker Desktop（Windows）会覆盖 `~/.docker/daemon.json`，且启用 containerd snapshotter 后 daemon 镜像配置不生效**，守护进程跑在 WSL2 VM 里，镜像只能通过 GUI（Settings→Docker Engine）配置。
- 最终方案（已验证跑通）：
  1. 直接从可用镜像源 `docker.1ms.run` 预拉取基础镜像并 `docker tag` 成标准名（python:3.12-slim / node:22-alpine）。
  2. Dockerfile 增加 `PIP_INDEX_URL`/`NPM_REGISTRY` 构建参数（默认官方源），compose 从 `.env` 透传，国内用清华 pypi + npmmirror。
  3. Nginx 加 `resolver 127.0.0.11` + 变量 `proxy_pass` 动态解析上游，修复后端容器重建后 IP 变化导致 502。
- 用户环境：Docker Desktop 29.6.1（Windows），守护进程运行中。
- 最终部署：5 容器全 Up（geap-db/geap-redis healthy），http://localhost/ 全链路 200，本周净利润 3068。
